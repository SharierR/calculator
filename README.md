# Cat Calculator App 🐱

A simple, charming calculator with a cat-themed skin built with HTML, CSS, and JavaScript.

## Features
- Basic math operations (addition, subtraction, multiplication, division)
- Keyboard support (number keys, operators, Enter, Backspace, Esc)
- Clear button animation (Animate.css fadeOutLeft)
- Cat-themed design with ears, face, whiskers, and paw-print buttons
- Soft warm gradient background with floating paw prints
- Responsive centered layout
- Glassmorphism display with paw-print accents

## Tech Stack
- HTML5
- CSS3 (custom properties, gradients, animations)
- JavaScript (vanilla)
- [Animate.css](https://animate.style/) for clear animation
- [Nunito](https://fonts.google.com/specimen/Nunito) via Google Fonts

## How to Run
1. Clone the repository or download the files.
2. Open `index.html` in your browser.
3. Use the buttons or keyboard to calculate.

## Live Demo
[https://sharierR.github.io/calculator/](https://sharierR.github.io/calculator/)

## Notes
- The cat skin is pure CSS — ears, face, whiskers, tail, and paw accents are all drawn with pseudo-elements and gradients.
- The display area uses a subtle glassmorphism effect with paw-print decorations in the corners.
- This project uses Animate.css for the clear animation effect.
